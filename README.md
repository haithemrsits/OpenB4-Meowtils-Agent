# Raven B4 for Lunar Client 1.8.9

This project allows you to run **Raven B4 (OpenB4)** natively on **Lunar Client 1.8.9** without needing Forge. It works perfectly as a standalone agent with Meowtils.

## Installation & Usage

1. **Place the files:**
   - Drop `RavenB4Loader-1.0.meowtils` into your extensions folder: `%appdata%\.minecraft\meowtils\extensions`
   - Drop `RavenB4.jar` into your main Meowtils folder.

2. **Load in-game:**
   - Launch Lunar Client and open the **Meowtils menu**.
   - Find the Raven B4 section and click **Load Raven B4**.

3. **Restart:** 
   - Fully restart your game to apply the injection. You're good to go!
